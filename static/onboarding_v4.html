Methodology

Why This Works

V4 now measures cumulative composition decisions. Each layer affects both the meal and context scene, creating a coherent behavioral profile rather than isolated picks.

Users naturally understand "build this plate" tasks. Layering avoids abrupt context switching and creates better continuity for preference elicitation.
Base deltas come from the chosen layer option. Decision speed and hover-switching scale each layer with a confidence multiplier.
Payload contract remains unchanged: dietary, occasion, cuisine, atmosphere, budget, noise preference, island, and current time.
